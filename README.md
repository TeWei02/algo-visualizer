演算法視覺化工具的規劃倉庫，目標是以互動式網頁展示資料結構與演算法的執行過程，降低學習門檻。

## 狀態

> **規劃中**：目前僅有架構構想，尚未開始撰寫程式碼。

## 規劃功能

| 功能 | 說明 |
|------|------|
| 排序演算法 | 氣泡、插入、合併、快速排序等逐步動畫 |
| 搜尋演算法 | 線性搜尋、二分搜尋視覺化 |
| 圖論演算法 | BFS / DFS、最短路徑（Dijkstra、A*） |
| 互動操作 | 調整資料規模、速度，觀察演算法行為 |

## 技術構想

- 純前端實作（HTML5 / CSS3 / Vanilla JavaScript），零依賴
- Canvas / DOM 動畫渲染，支援深色模式
- 可部署至 GitHub Pages
